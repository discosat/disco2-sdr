# disco2-sdr
This repository contains the flowgraphs, recordings, documentation and other files for the Software Defined Radio (SDR) portion of the groundstation.

For the documentation for DISCO1, check the [disco_gnuradio](https://github.com/discosat/disco_gnuradio) repository.

For instructions on setting up the hardware for testing, check the hardware installation guide. Note that this guide is meant for the hardware available at the DASYA Lab at the ITU and might require slight changes for your setup.

## Note about recordings

You will notice that the TX flowgraphs have a `File Source` transmitting a recording of a signal. These recordings, usually saved as `.raw` are too big for github. You can find them in the nextcloud instance under:

`/DISCO/ITU-GS/SDR/2026-03-11-disco2gs-ping-recordings`
